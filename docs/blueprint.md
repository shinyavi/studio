# **App Name**: Memento Daily

## Core Features:

- Reminder Creation: Users can create new daily reminders with custom text and scheduling options.
- Daily Display: The app displays reminders for the current day in a clear, organized format.
- Completion Tracking: Users can mark reminders as complete.
- Scheduled Reminders: Schedules daily reminders, allowing to pick different days and times to send reminders.

## Style Guidelines:

- Primary color: Deep purple (#673AB7) for focus and tranquility.
- Background color: Very light purple (#F3E5F5), nearly white, providing a calm backdrop.
- Accent color: Analogous indigo (#3F51B5) for highlighting active elements.
- Body and headline font: 'Inter' for a clean and modern aesthetic.
- Simple, outline-style icons for navigation and actions, in a lighter shade of purple.
- Clean and minimalistic layout with clear separation of reminder elements.
- Gentle animations on reminder completion.
